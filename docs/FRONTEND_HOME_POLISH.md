# 首页与公共框架优化 — 阶段交付

本轮范围为首页、移动页面布局、主导航、周期选择器、按钮及公共过渡。保留Vue标准分层和现有API，不改MySQL数据模型、不实施指数算法，也不部署服务器。以现有设计的纯黑金融风格为基础整理细节，不将本轮实现称为已通过全部产品验收。

## 完成的行为

- 首页采用对齐的身份行、等宽数字与单位、涨跌符号、明确的演示标记、行情读数区和中性待评估状态。
- 刷新入口真实重新请求首页。首次读取显示骨架；刷新已有数据时保留内容；失败明确标记上次数据，重试成功才更新时间。客户端“读取于”不等于行情实时更新。
- 最近事件提供完整详情入口，长标题单行省略，空列表可进入现有事件创建页。待评估事件不显示绿色收益。
- 周期控件使用一个滑动背景，仍支持方向键、Home/End和单一Tab入口；再次按当前周期不发出重复变更。
- 图表切换使用短淡入，不造新数据、不重新计分。选点读数占固定区域，避免提示框覆盖行情；关闭选点后焦点回到图表。拖动通过requestAnimationFrame合并更新，切周期/卸载时取消未完成回调。
- 主导航有稳定的选中底色和图标按压，主页面切换使用淡入；进入详情与返回采用相应方向的短位移。
- 页面包裹在单根过渡容器中；退出的页面不可交互且从辅助技术中隐藏，重新进入时恢复。主页面记录滚动位置，浏览器返回优先恢复浏览器保存位置。
- 统一按钮按压、忙碌状态、焦点轮廓、输入焦点和原生确认框过渡；不把破坏性按钮的红色样式误当成保存失败反馈。
- 顶/底部依实际safe-area留白；窄屏及短屏保持自然滚动。减少动态效果时关闭位移动效、滑动和持续旋转，保持状态可读。

## 动效规范

| 项目 | 当前取值 |
|---|---|
| 快速反馈 | 120ms |
| 常规状态/指示器 | 220ms |
| 页面进入 | 280ms |
| 标准缓动 | cubic-bezier(0.2, 0, 0, 1) |
| 进入/回弹缓动 | cubic-bezier(0.22, 1, 0.36, 1) |
| 页面位移 | 进入12px，退出6px |
| 按钮按压 | scale(0.975)，translateY(1px) |

所有参数集中在 `src/assets/styles/tokens.css` 和 `motion.css`。主要过渡只改变transform/opacity；没有人为延迟接口成功、数字计数动画或常驻will-change。没有执行完整性能基准、低端机帧率评测或服务器部署。

## 阶段检查结果（2026-10-13）

- 生产构建、TypeScript、ESLint及源码格式检查通过。
- 5个首页/公共组件测试文件、24项测试通过。覆盖原有首页边界、超时及旧请求竞争，以及新增刷新失败保留旧数据、周期重复按压、选项变化的键盘入口、图表选点/焦点返回、卸载取消拖动回调。
- Playwright只读检查320×640、393×852、430×932、800×900：没有横向溢出，滚动后末条事件未被固定导航遮挡。
- 检查图表键盘操作、周期选择、刷新失败保留旧数据及重试、连续主导航切换后旧层清理、骨架到数据切换、减少动态效果；无浏览器pageerror。
- 浏览器阶段检查只发送GET请求，未提交表单或修改MySQL记录。原生Android项目及其本地调试配置没有纳入本轮提交；检查工具排除生成的android目录。
- 预览与阶段输出存于本地忽略目录 `.cache/home-polish`。没有将设计稿或截图上传公开仓库。

这是局部阶段检查通过，不能写成五模块业务验收、真机验收或企业级认证完成。正式业务测试仍按用户约定统一开展。

## 休息后统一验收

1. 首页是否仍像专业金融行情应用，字重、黑白层级和绿色走势是否合适。
2. 按钮、导航和周期滑块是否响应自然，快速重复操作是否稳定，动画是否过多或过慢。
3. 切到详情再返回时，焦点、滚动位置、底部导航是否正确；短屏与键盘弹出场景仍需真机检查。
4. 打开系统减少动态效果，确认选择状态和加载状态可理解。
5. 在首页刷新时模拟服务不可用，确认旧数据提示、重试及加载形态；开发环境 `/?preview=error` 与 `/?preview=empty` 可查看初始失败和空状态。
6. 在iOS Safari/Android WebView及实际网络环境补充触摸、系统安全区域和性能检查。
